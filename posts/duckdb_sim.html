The

Code 
duckplyr_slow = function(val_df) {
  val_df |>
    as_duckplyr_tibble() |> 
    summarise(.by = g,
              p = 2*pt(abs(mean(x) * sqrt(6) / sd(x)),
                       df = 5, lower.tail = FALSE)) |> 
    as_tibble()
}

So to get a fast version we have to include a few extra steps:

  • The group-wise means/sds are calculated in their own step (similar to what data.table required in the previous post)
  • An arrange(g) step, since all the other competitors maintain the ordering of the groups.
Code 
duckplyr_fast = function(val_df) {
  val_df |>
    as_duckplyr_tibble() |> 
    summarise(.by = g,
              mx = mean(x),
              sx = sd(x)) |> 
    mutate(p = 2*pt(abs(mx*sqrt(6) / sx),
                    df = 5, lower.tail = FALSE)) |> 
    arrange(g) |> 
    select(-mx, -sx) |> 
    as_tibble()
}

For comparison, here is the collapse version:

Code 
collapse_soln = function(val_df) {
  val_df |>
    gby(g) |>
    smr(p = 2 * pt(abs(fmean(x) * sqrt(6) / fsd(x)), 
                   df = 5, lower.tail = FALSE))
}

Here we run an updated benchmark. I added a check function to make sure they all produce the same result.

Code 
check_fun = \(x,y) length(waldo::compare(x, y, ignore_attr = TRUE, tolerance = 1e-8)) == 0

bench_res = bench::mark(duckplyr_slow = duckplyr_slow(val_df),
                        duckplyr_fast = duckplyr_fast(val_df),
                        collapse = collapse_soln(val_df),
                        check = check_fun, 
                        min_iterations = 2)
