# Plot a correlation matrix Generate a colorful heatmap visualization of a correlation matrix

Plot a correlation matrix Generate a colorful heatmap visualization of a
correlation matrix

## Usage

``` r
plot_cor_mat(cor_mat, bug_name = NULL)
```

## Arguments

- cor_mat:

  a correlation matrix

- bug_name:

  a string giving the name of the bug

## Value

a ggplot of the correlation matrix
